## VDHelper 0.2.0 — 让「通过」这两个字先被证明

0.1.0 解决的是「头显找不到 PC」这一层的**检测覆盖**。0.2.0 处理的是一个更隐蔽的问题：
**这个工具自己会不会在没测到的时候说通过。**

### 三个界面

- **本机体检**：**35 项**检测（本机体检这一屏跑的数）。连同只在第三屏跑的 `headset-deep`，共注册 **36 项**。0.1.0 是 18 项。
  （不写当次的通过/警告条数：那是一次实测的快照，会随机器状态变，写死在发布说明里只会误导。）
  新增覆盖 GPU 硬件编码器与降频、显示适配器健康（`ConfigManagerErrorCode` 解码）、
  无线链路频段/信道/信号、发现端口归属、APIPA 残留、厂商调校常驻工具、路由出向策略、深度丢包探测。
- **串流参数**：111 个配置键。DPAPI 密文**不显示**（0.1.0 的界面里会打印 `AQAA...` 前缀，已改）。
- **头显诊断**：除包名/权限/网络外，**新增判断客户端进程是否还活着**——这是区分「闪退」与
  「列表空」的唯一依据，两者修法完全相反。

第一屏顶部新增 **「接下来做什么」**：失败项排最前、可修的其次、只是解释的再次，
并且**不做条数上限**（早期版本截断到 6 条，反而把 VD 显示器驱动被禁用这条藏掉了）。

### 修掉的「假通过」

| 层 | 原来 | 现在 |
|---|---|---|
| 判定 | 全部 Unknown 也报「体检通过」 | 测到的必须比没测到的多才敢报通过 |
| 判定 | 30 项读不到 + 3 项通过 = 通过 | 同上，报「无法判定」并说明这不是通过 |
| 退出码 | 靠匹配自己打印的文本，且与文案矛盾 | 直接取判定值 |
| 写入 | 四条写入路径都只看函数返回 | 全部回读确认后才说成功 |

> **后补（2026-10-06）**：上面那行「现在」是**写于 0.2.0 发布时**，不是对今天的描述。
> 后续复核（`research/15-review/03-fix-audit.md` F4/F6）发现四条写入路径里有两条至今仍只看退出码：
> `fw-restore-vd`（`netsh`）与 `svc-repair`（`msiexec`）。
> `streamer-launch` 已在 F6 修好——它现在轮询进程并报 PID。
> `enable-pairing-requests` 一直在回读。**要确认串流用的哪条路径，看 `--apply --list` 里的「执行」行。**
| 配置 | 损坏的配置说成「Streamer 从未运行过」 | 分开「没有」与「坏了」 |
| 查询 | cmdlet 不存在时 stderr 被丢弃 → 通过 | stderr 进证据，报 Unknown |
| 枚举 | `gpu-pick` 零块显卡也说通过 | 零块 → Unknown |

### 修掉的两处「生成对了但呈现错了」

- **文档站**：`.tblwrap` 的 `overflow-x:auto` 让 `th` 的 `position:sticky` 相对表格而非页面解析，
  **每一张表的第一行都被表头盖住**——包括最常被找的 S1「看不见电脑」整行。
- **HTML 报告**：只转义不转换，`**粗体**` 原样发进准备贴到 issue 的文件里。

### 修复动作收敛到两条

`--apply --list` 现在只列两项，都非破坏性、都自查结果：
`streamer-restart`（比较重启前后 PID）、`enable-pairing-requests`（回读配置确认）。
0.1.0 里的「禁用 APIPA 网卡」已移除——那些网卡本来就是 Down 的，禁用不改善当下行为，
只会永久移除 Wi-Fi 与蓝牙网络连接。

### 已知盲区（工具会明说）

「头显到底有没有把发现包发出来」与「包到了但 PC 没回」需要抓包或读头显侧日志，
两者本工具都做不到。`udp-discovery` 通过时**不代表头显那边没问题**，会在文案里写明这一点。

### 无头用法

```
VdHelper.exe --selftest [--out f] [--symptom S1..S7]   退出码 0/3/4/5
VdHelper.exe --apply <fixId> | --apply --list
VdHelper.exe --set-param <key> <json>
VdHelper.exe --report out.md | --report-html out.html
VdHelper.exe --deep [--samples N]                     丢包与抖动探测
```

与 0.1.0 相同。报告不写任何 DPAPI 密文 / 令牌 / 账户条目内容，机器名与局域网地址保留。
