# VDHelper 0.3.0 —— 别让工具替你说谎

上一版之后修的全是同一类东西：**生成对了，但呈现出来是错的**。有的错在代码，有的错在你读到的文字。

## 修复：三个需要管理员的修复，从没提示过要提权

界面和两种报告里的"会弹 UAC，需要你点确认"，来自 `FixAction.NeedsElevation`。只有两个修复设了它。
另外三个同样需要管理员权限，一个字都没说：

| 修复 | 实际执行的动作 | 之前 |
|---|---|---|
| `fw-restore-vd` | `netsh advfirewall firewall add rule` | 静默失败 |
| `svc-start` | `Start-Service VirtualDesktop.Service` | 静默失败 |
| `disable-adapter` | `Disable-NetAdapter` | 静默失败 |

现在三个都带提示。

顺带删掉一个**在说谎的参数**：`PowerShellRunner.RunAsync` 的 `asAdministrator` 接收后直接丢弃
（`ProcessStartInfo.Verb` 在 `UseShellExecute=false` 时无效，注释里有写）。但调用方看到
`RunAsync(script, asAdministrator: true)` 会理所当然以为它会提权。参数已移除，注释改为说明
为什么不存在这个开关，并指向真正管用的 `NeedsElevation`。

## 修复：`--report` 被 `--selftest` 吞掉

```powershell
VdHelper.exe --selftest --report issue.md
```

以前只打到 stdout、**不写文件、无警告**。在求助帖里这就是一个空附件。
现在报告标志排在 `--selftest` 之前——两条路跑的是同一个引擎，指定文件名是更明确的要求。

## 修复：文档里三处对不上的数字

| 位置 | 之前 | 现在 |
|---|---|---|
| README 两处加粗 | `**「接下来做什么」**` 等，原样输出星号 | 正常加粗，并加了闸门 |
| 发布说明 | 写着某次实测的通过/警告条数 | 删掉（会随机器状态漂移，写死只会误导） |
| 常见问题 · 覆盖度 | 9/23 已覆盖、10 未覆盖（对着 18 项检测的旧断言） | **15/23**，剩 2 项 |
| 首页 | "27 条待检测项 vs 35 条实装，差额是还没实现的" | 方向讲反了：是清单没跟上工具 |

覆盖度那 10 条是**逐条对着现在的检测项重新核过**才改的，每条"现已覆盖"都先在实跑输出里确认
检测项存在。其中 C2「主动探测」记为**有意不做**并附理由：试过向 `127.0.0.1:38850` 发 17 字节
探测包，而 17 字节包在协议里是连接前的单播预告包，PC 侧命中该分支会**关闭本次运行的 38850
监听 **（`-.112.cs:354`）**。

## 工具链

- `capture-docs.ps1` 现在带 `--force-prefers-reduced-motion`。统计卡是 ~1.1 秒的递增动画，
  以前截图总拍到中间帧——**35 被拍成 3**，看起来像过期数字。
- 仓库清掉 492 KB 一次性产物（自检输出、截图）。`.gitignore` 当时是一个字母一个字母枚举的
  （`_[a-z].txt`、`_t?.png`），两字符以上或带数字的直接漏进来——那不是规则，是"至今犯过的错
  的清单"。改成 `/_*`。
- `check-symptom-map.ps1` 增加两项检查：`**` 夹在文字与中文标点之间（CommonMark 不认作开始符，
  GitHub 原样输出星号）；README 里的版本号必须与 `VERSION.txt` 一致。

## 关于 v0.2.0 的说明

v0.2.0 的发布页写的是"让「通过」这两个字先被证明"。**它的资产在那之后被反复覆盖过多次**，
现在下载到的不一定是发布当时那一份。原因是我把"上传新构建"当成了默认动作，而不是"该发新版本"。
从这一版起：**资产与标签不再原地覆盖，改版就发新标签。**
