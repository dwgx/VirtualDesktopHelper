# VDHelper 0.7.0 —— 让人来审自己的结论

0.6.0 之后 41 个提交。分成两块：**两份自审找出来的缺陷**，和**把验证变成闸门**。
这一版的重点不再是「又修了哪些文案」，而是**这个工具开始有人（除了作者）逐条核对它的每一句话**。

## 一、两份自审：13 处「说的比测的多」

派了两个只读审计 agent，只问一个问题：**用户能看到的文字，有没有断言这段代码没有建立的东西。**
问题问得很窄，所以挖出来的东西很集中——**全是同一个形状：一句话宣称得比它采集到的更多。**

| 缺陷 | 之前怎么说 | 实际发生的事 |
|---|---|---|
| `PreferredCodec` 等 4 键 | 类型是 `int (enum …)`，`StartsWith("enum")` 为假 → 枚举表从未被调用 | `--set-param PreferredCodec 999` 写进去了，**而同一键的字符串 `"999"` 却正确拒绝**。同键，两种答案 |
| `FoveaSize` 等 10 个浮点键 | 范围写成 `UI 滑块 0.4–1.0`，左半段解析失败 → 边界塌成空 → 整段范围检查被跳过 | `--set-param FoveaSize 999` 写进去了 |
| `--adb` / `--deep` / `--apply` | 报告声称「不写任何 DPAPI 密文、令牌、账户条目」 | 这三条控制台路径一个字都没过脱敏，而 adb shell 原始回包正是最容易带出这种东西的地方 |
| IPv6 套接字 | `Split(':')[0]` 切出 `fe80` 解析失败 → 落进「非本网段」桶 | 写成「到公网的已建立连接」——而 `fe80::` 是链路本地，就在这根线上 |
| `gpu-throttle` 温度分支 | 没做掩码 | `0x0` 拼成空列表，输出「驱动报的降频原因：。」这种空列表；`GpuIdle` 也被当成降频原因，而同一文件的注释自己说它是正常状态 |
| `nat-type` | 摘要说「这条双层 NAT 结论不成立」 | **下一行的指引照原样断言了它** |
| `wifi-quality` | 告诉用户「数值自相矛盾」 | **两行后又说「你确实连的是拥挤的 2.4 GHz」**——把刚撤回的结论又说了回去 |
| `net-loss` | 一个目标不应答 + 另一个 30% 丢包 | 30% **只存在于证据里**，不进摘要；而指引**拿同一个网关当"本机链路没问题"的证据** |
| `lan-reach` 邻居状态 | 三元只判 `reachable` | `Probe`（正在解析）被写成「已过期」 |
| `nic-powersave` | 「两者都读进证据了」 | `Get-NetAdapterPowerManagement` **根本不返回**设备管理器那个勾选项 |

**审计还抓到我自己的注释编造证据**：位表注释说节流分支「已由真机验证，依据是 89% 负载和 100.8 W」。
全仓 grep，**100.8 W 不存在**；**89% 是另一次记录的频率比，被读成了占用率**。已改成真正在册的那次
（`docs/checks.md:44`——71%、2205/3090 MHz、53% 占用、69 °C、90.1 W、软功耗墙），**错误保留可见而不是删掉**。

参数校验器用**直接调用发布程序集的探针**对全部 111 行逐行验过，不是抽样：**19 个用例，0 失败**。

## 二、顺带挖出的两个静默错误

**显卡名里有一个逗号**，`nvidia-smi` 就多输出一列，而解析读 `parts[0..7]` 并用「字段数 < 8」兜底——
**兜底通过，每个值整体前移一格，CurrentClock 拿到名字的尾巴，解析失败，显卡被报成 0 MHz。**
静默而且错。现在从末尾取后七个字段。**这台机器的卡名没有逗号，所以它在真机上永远暴露不出来。**

**Markdown 强调渲染不出来**：`**…断了。**Windows` 里闭合标记夹在全角句号和拉丁字母之间，**不是右贴合法则**，
于是 span 永远不闭合——**贴进 issue 时用户看到的是四个字面星号**。连续三次跑 `--report`，字面 `**` 已为 **0**。

## 四、界面

圆角窗口走 `WindowChrome.CornerRadius="8"` 而不是计划里写的 `AllowsTransparency`——
**后者会关掉 DWM 硬件加速，而健康页是让人滚动着读三十多行证据的列表。**
同理，为了八像素不值得把窗口踢下 GPU。

**参数页的值列原来会截掉那个默认值**（`（未设置 → 用默认值 tru…`），而「不改的话它会是什么」正是这个页
存在的理由。现在是 `未设置（默认 true）`，整行放得下。

**每一行现在都标 `PC 侧` 或 `头显侧`**：111 行里 57 行落在头显，此前唯一的区分线索是**它没有切换按钮**。

## 五、已知未覆盖

- **头显侧代码路径一次都没在真机上跑过。** 串流通了（本机实测 4 个已建立通道与 Windows 逐条对上），
  但 `adb devices` 仍为空——**串流通不等于 adb 通**。第三屏要开无线调试或插 USB-C 才有内容。
- `GpuRuntimeChecks` 的 CSV 解析**已在真机验证**（`NVIDIA GeForce RTX 5070 Ti Laptop GPU, 2070, 3090, 60, 37, 2, 59.44, 0x…`，8 字段顺序正确）。
- 补丁 APK 的行为仍**未经真机验证**。
